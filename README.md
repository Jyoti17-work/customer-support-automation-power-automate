# Customer Support Automation using Power Automate Desktop

## Project Overview
This project automates customer support monitoring using Power Automate Desktop. The workflow reads customer support ticket data from Excel, identifies low customer satisfaction (CSAT) ratings, and automatically sends email alerts to managers using Gmail SMTP integration.

---

## Features
- Automated Excel data processing
- CSAT monitoring workflow
- Conditional logic for low ratings
- Automated email notifications
- Gmail SMTP integration
- Power BI reporting support

---

## Technologies Used
- Power Automate Desktop
- Microsoft Excel
- Gmail SMTP
- Power BI

---

## Workflow
1. Read customer support ticket data from Excel
2. Iterate through ticket records
3. Detect ratings less than or equal to 3
4. Trigger automated email alerts
5. Generate reporting workflow
